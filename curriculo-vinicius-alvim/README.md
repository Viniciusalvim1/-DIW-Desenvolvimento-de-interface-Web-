## Descrição

Página de currículo pessoal desenvolvida com HTML e CSS puros, conforme solicitado na atividade da disciplina. O projeto utiliza elementos semânticos do HTML e estilos organizados em um arquivo CSS separado, com design inspirado na identidade visual da Lumia (lumiaclin.com.br).

## Estrutura de Arquivos

```
/
├── README.md
└── public/
    ├── index.html       ← página principal (currículo)
    ├── projetos.html    ← página futura (projetos)
    ├── contato.html     ← página futura (contato)
    ├── styles.css       ← folha de estilos
    └── img/
        └── foto.jpg     ← foto de perfil
```

## Elementos HTML utilizados

- Metadados (`<meta>`, `<title>`, `<link>`)
- Estrutura semântica: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`
- Textuais: `<h1>` a `<h3>`, `<p>`, `<strong>`, `<span>`, `<ul>`, `<li>`
- Multimídia: `<img>`
- Links: `<a>` com `href`, `target`, `mailto:` e `tel:`
- Tabelas: `<table>`, `<thead>`, `<tbody>`, `<tr>`, `<th>`, `<td>`

## Propriedades CSS aplicadas

- Variáveis CSS (`--navy`, `--teal`, etc.)
- Box model: `margin`, `padding`, `border`, `border-radius`
- Display e layout: `flex`, `gap`, `flex-wrap`
- Tipografia: `font-family`, `font-size`, `font-weight`, `letter-spacing`, `text-transform`
- Cores e fundos: `color`, `background-color`, `background: linear-gradient()`
- Efeitos: `transition`, `:hover`, `:nth-child()`
- Position: `position: sticky` na navegação
